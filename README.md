# Operations Performance MIS

An end-to-end Operations Performance MIS project designed to simulate a real-world back-office operations environment.

## Objective

The project analyzes operational performance across employees, teams, processes, shifts, quality, SLA, attendance, productivity, and workload.

The goal is to build a practical MIS system that helps operations managers monitor daily performance, identify bottlenecks, and take data-driven actions.

## Business Scenario

The project simulates a back-office document processing operation where employees process incoming records while being monitored for:

- Productivity
- Quality
- SLA performance
- Attendance
- Workload
- Backlog
- Errors and rework
